# ゆらぎ水槽

ブラウザで動く、手軽なアクアリウム育成ゲーム。

魚やエビを迎えて、餌をあげて、小物を飾る。それだけ。

## 水槽

地域ごとに水槽を持てる。コインで解放して、上のバーの水槽名から切り替える。
水の色・砂の色・光の色は水槽ごとに変わる。

| 水槽 | 価格 | 住人 |
|---|---|---|
| 日本の淡水魚 | 最初から | メダカ、金魚、タナゴ、オイカワ、ドジョウ、ヨシノボリ、ミナミヌマエビ、スジエビ、石巻貝 |
| 熱帯魚水槽 | 1400 | ネオンテトラ、グッピー、コリドラス、ベタ、エンゼルフィッシュ、レッドビーシュリンプ、ラムズホーン |
| 日本の海水魚 | 4200 | チンアナゴ、カクレクマノミ、ルリスズメダイ、デバスズメダイ、ミナミハコフグ、ヤドカリ |

生きものもかざりも、住む場所にしか置けない。コインは全部の水槽から合算でたまり、
世話が必要な水槽があると水槽名の横に点がつく。

## 遊びかた

- **えさ** — 押すと餌の容器を取り出す。水槽をタップすると容器が傾いて、その場所に餌が沈んでいく。まく位置は毎回自分で決める
- **ショップ** — 今の水槽に合う生きもの・かざりを買う（最大16匹 / かざり10個）
- **そうじ** — 濁った水をきれいにする
- **あかり** — 消すと夜モード。魚がゆっくりになる
- 魚をタップすると名前をつけられる
- **かざり** — タップで選んで、左右にドラッグで移動、スライダーで大きさを ×0.5〜×2.0 に変更
- **住人** — 右上の住人チップにホバー（スマホはタップ）すると、種類ごとの匹数・稼ぎ・平均満腹度と、空腹の子が何匹いるかが出る
- **図鑑** — メニューから。全22種の状況と、まだ解放していない種の条件が並ぶ
- コインは魚の満腹度と水質に応じて自動でたまる（閉じている間も最大12時間ぶん）

魚は餓死しない。お腹が空くと色が薄くなって稼ぎが落ちるだけ。
エビと貝はコケが主食なので、餌をやらなくても自分で食べていける。水が濁っているほどよく食べる。

## 解放

水槽そのものはコインで買う。水槽の中の生きものは**飼育の実績**で解放する。

| 生きもの | 条件 |
|---|---|
| スジエビ | この水槽で3種類以上の生きものを飼う |
| ヨシノボリ | 岩と流木をあわせて3つ置く |
| タナゴ | メダカを3匹、満腹80%以上で6時間 |
| ドジョウ | 水質90%以上を12時間 |
| オイカワ | きげん85%以上を24時間 |
| ベタ | 熱帯魚水槽の住人を8匹以上にする |
| エンゼルフィッシュ | 熱帯魚水槽のきげん90%以上を12時間 |
| カクレクマノミ | 海水水槽にイソギンチャクを置く |
| ミナミハコフグ | サンゴかイソギンチャクを3つ置く |
| ヤドカリ | 海水水槽の水質95%以上を12時間 |

## 構成

`index.html` の1枚だけ。ビルド不要、依存パッケージなし、サーバー処理なし。

- 水槽の中身は HTML5 Canvas に毎フレーム描画。画像素材は一切なし
- 魚も小物もベジェ曲線で手描き。魚種は「体の縦横比・色・尾の形・模様」のパラメータ違い
- 岩は乱数で歪めた閉曲線、流木とサンゴは太さが先細る帯として描画。木目・ひび・コケは形状でクリップして乗せている
- 画面まわり（バー、ショップ、ボタン）は通常の HTML + CSS
- セーブは `localStorage`（ドメインごとに独立）。表示していない水槽は正規化座標で保持する
