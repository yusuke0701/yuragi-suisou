# ゆらぎ水槽

ブラウザで動く、手軽なアクアリウム育成ゲーム。

魚やエビを迎えて、餌をあげて、小物を飾る。それだけ。

## 遊びかた

- **えさ** — 押してから水槽をタップすると、その場所に餌が沈んでいく
- **ショップ** — 魚・エビ・貝・かざりを買う（最大16匹 / かざり10個）
- **そうじ** — 濁った水をきれいにする。エビと貝は入れておくと濁りにくくなる
- **あかり** — 消すと夜モード。魚がゆっくりになる
- 魚をタップすると名前をつけられる
- **かざり** — タップで選んで、左右にドラッグで移動、スライダーで大きさを ×0.5〜×2.0 に変更
- **チンアナゴ** — 砂に穴を掘って住みつく。潮に合わせて揺れ、餌が流れてくると首を伸ばす。魚が近くを通ったりタップされると砂に引っこみ、夜は頭だけ出して寝る
- コインは魚の満腹度と水質に応じて自動でたまる（閉じている間も最大12時間ぶん）

魚は餓死しない。お腹が空くと色が薄くなって稼ぎが落ちるだけ。

## 構成

`index.html` の1枚だけ。ビルド不要、依存パッケージなし、サーバー処理なし。

- 水槽の中身は HTML5 Canvas に毎フレーム描画。画像素材は一切なし
- 魚も小物もベジェ曲線で手描き。魚種は「体の縦横比・色・尾の形・模様」のパラメータ違い
- 岩は乱数で歪めた閉曲線、流木とサンゴは太さが先細る帯として描画。木目・ひび・コケは形状でクリップして乗せている
- 画面まわり（バー、ショップ、ボタン）は通常の HTML + CSS
- セーブは `localStorage`（ドメインごとに独立）

## ローカルで動かす

ファイルを直接ブラウザで開くだけで動く。

```
open index.html
```
